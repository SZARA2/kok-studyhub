# 콕 통합: 팀용 독립 스킬

각 기능의 지침을 따로 수정하고, 한 Grok Bot이 실행하는 소스 묶음입니다. 학습 기능은 공통 `lecture.md`를 사용하며, 시간표 일정은 강의 자료 없이도 실행합니다. AI 작업과 웹 생성은 각 스킬이 수행합니다.

- `kok-lecture-collector`: 링크·파일·강의 내용을 모아 출처와 누락을 기록한 `lecture.md` 생성.
- `kok-problem-drill`: 1번. 근거가 있는 내용을 단계별 객관식 풀이 카드로 구성.
- `kok-podcast`: 2번. NotebookLM의 실제 대화형 오디오 생성·다운로드.
- `kok-concept-lab`: 3번. 예측·실험·검증 순서로 조작하는 3D 시각화.
- `kok-schedule`: 4번. 사용자가 올린 시간표 이미지·PDF·텍스트를 확인하고 주간 수업과 복습 계획을 표시.
- `kok-router`: 공통 입력과 번호 1~4를 해당 팀용 스킬에 연결.
- `kok-onboarding`: 시작 안내와 검토한 소스의 스킬 업데이트 절차.

앱의 스킬과 GitHub의 파일은 별도 사본입니다. [담당자·업데이트 절차](../docs/SKILL_WORKFLOW.md)에 따라 버전과 본문을 함께 확인하세요. 원본 템플릿에서 가져온 읽기 전용 스킬과 이름을 구분해 팀용 스킬만 라우터가 실행하도록 합니다.

## 사용

1. 팀용 스킬이 포함된 통합 Bot을 추가합니다.
2. 강의 링크·파일·직접 쓴 내용을 보내 `lecture.md`를 만듭니다. 일정 기능은 먼저 시간표를 요청하며 `lecture.md` 없이도 작동합니다.
3. 채팅에서 번호나 기능명을 요청합니다. 웹의 번호 메뉴는 생성된 결과를 보여 줍니다.
4. 개선 의견이나 수정 문서를 보내 `문제 풀이 스킬을 이 내용으로 업데이트해 줘`처럼 요청합니다. 봇은 해당 내장 스킬과 리소스를 수정하고, 저장된 본문·버전을 다시 읽은 뒤 실행을 확인합니다.

GitHub는 팀의 소스 검토·백업에 사용할 수 있습니다. GitHub 수정이 앱에 자동 반영되지는 않습니다. 공유 템플릿을 갱신해도 다른 사람의 기존 사본은 별도로 업데이트해야 합니다.

## 공유 사본의 준비

공유 템플릿은 스킬 지침을 전달합니다. 기존 컴퓨터의 리소스 파일·로그인·대화 기록은 전달되지 않습니다. 봇이 템플릿 메모리의 실제 고정 URL과 SHA256으로 리소스·검증 코드를 직접 준비합니다. 사용자에게 수동 ZIP 첨부를 먼저 요구하지 않습니다. 이후 AI 작업과 웹 생성은 그 Bot의 컴퓨터에서 수행합니다.

한 Bot에 수집·안내·라우팅과 1~4번 기능을 함께 공유할 수 있습니다. 웹의 메뉴는 만들어진 결과를 열며, 새 자료 수집이나 새로운 생성은 Bot 채팅에서 요청합니다. 웹 입력과 Bot 실행을 잇는 장치·웹훅 연결은 이후 연동 범위입니다.

NotebookLM은 사용하는 계정에서 로그인이 필요합니다. 다른 사람의 로그인이나 개인 드라이브는 템플릿에 포함되지 않습니다. 대본만 생성된 상태는 오디오 완료가 아닙니다. 이번 묶음은 YouTube 수집과 누코드/USB 입력을 포함하지 않습니다.

## v1.2.2 실행과 전달

선택한 스킬의 데이터만 만든 뒤 `python3 tools/build_web.py <작업폴더> --out <작업폴더>/web/index.html`을 실행합니다. 없는 기능은 미생성으로 표시합니다. 공통 화면을 임의의 간단한 채점 HTML로 대체하지 않습니다. `python3 tools/verify_web.py <작업폴더>/web/index.html --require-mode 1`처럼 선택 기능과 실행 ZIP을 확인하고 HTML·ZIP을 함께 첨부합니다. 사용자는 HTML을 눌러 미리보기에서 바로 학습합니다. 3D는 srcdoc, 16MB 이하 음원은 data URL로 내장합니다. 개별 3D HTML·음원·팟캐스트 HTML도 첨부하며 ZIP은 보관용입니다. topic_generated 자료에는 강의 원문 미제공 표시를 유지합니다. NotebookLM 로그인은 2번 팟캐스트를 선택했을 때만 확인합니다.
