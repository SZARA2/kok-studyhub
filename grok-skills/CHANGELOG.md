# v1.2.2 (2026-11-01)

지정 화면 재사용, 기능별 부분 생성, 필요한 파일을 포함하는 실행 ZIP과 검증 영수증, 출처 표시 보존, 팟캐스트 선택 시에만 로그인 확인.

# 변경 이력

## v1.2.1 — 2026-11-01

- "Quiz me on a topic → 컴퓨터 사이언스"가 채팅 문답으로 끝나는 분기를 수정합니다. 주제만으로도 기초 노트와 실제 HTML 문제 웹을 생성합니다.
- 주제 기반 Bot 작성 자료를 수집한 강의 원문과 구분합니다.
- 한국어 첫 안내, 실제 HTML 첨부 완료 조건, 첫 실행 리소스 자동 준비를 최상위 실행 지침과 맞춥니다.

## v1.2.0 — 2026-11-01

- 최신 원본 여섯 스킬을 병합하고, 실제 Grok Bot의 일곱 스킬을 같은 버전으로 등록했습니다.
- 수식 표시와 문제 피드백, 자료에 근거한 3D 실험실, 모노 MP3 출력을 반영했습니다.
- 일정은 사용자가 올린 시간표를 사용하며 강의 자료 없이 실행합니다.
- 피드백·수정 문서로 담당 내장 스킬을 갱신하고 저장 본문을 다시 확인합니다.
- 새 계정용 리소스 묶음과 해시 검증 도구를 제공합니다. 웹 제목과 출처는 현재 lecture.md에서 읽습니다.
- YouTube와 실제 누코드 입력은 이번 범위에서 제외합니다. 실제 GPU 및 generic 외 여섯 3D 장면은 검증하지 않았습니다.

## v1.0.1 — 2026-11-01

- 일곱 스킬을 담당자별 파일로 관리하고 공통 `lecture.md`와 번호 1~4의 연결을 유지합니다.
- GitHub의 검토된 고정 커밋에서 본문·리소스·검증 코드를 함께 준비하고 파일 해시를 확인합니다.
- 템플릿 스킬 조회 누락 시 앱에 설치되지 않았다고 단정하지 않고 수정 가능한 팀용 사본의 등록·읽기 확인 절차를 적용합니다.
- `스킬 업데이트` 요청은 실제 앱 본문과 버전 반영까지 확인합니다. 자동 동기화와 구분합니다.
- 문제·보기·해설·힌트의 HTML 실행과 스크립트 데이터 탈출을 막고 세 가지 안전성 회귀 검사를 추가합니다.
- 원본 작성자, 담당자, 개별 버전, 출처/누락 표식을 보존합니다.

## v1.0.0 — 2026-11-01

용철님의 원본 여섯 스킬과 인수의 수집·정리 스킬을 읽어 통합 봇의 일곱 팀용 스킬과 첫 데모를 만들었습니다.
