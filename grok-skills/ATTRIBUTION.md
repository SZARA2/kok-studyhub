# 스킬의 유래

용철님의 공개 [콕 통합 템플릿](https://x.ai/bot/FqWdwcTo_72g1MnyvItD8)을 사용자 승인 후 계정에 가져와, 앱이 표시하는 읽기 전용 스킬 원문 여섯 개를 Codex가 읽고 보존했습니다.

- `kok-getting-started` → `kok-onboarding`
- `kok-button-router` → `kok-router`
- `problem-drill` → `kok-problem-drill`
- `notebooklm-studio-pack` → `kok-podcast`
- `concept-lab-visualizer` → `kok-concept-lab`
- `klas-deadline-cards` → `kok-schedule`

인수의 기존 `콕봇 강의 수집·정리·인계 v2`는 `kok-lecture-collector`의 기반이며, 임시 출제·학습웹 스킬은 출처 구분에 참고했습니다. 각 파일에 원문 본문의 SHA-256과 변경 이력을 남겼습니다. 원본은 검증용 비공개 작업 자료에 보존하고 이 공개 폴더에는 팀용 파생 스킬과 공통 리소스만 넣었습니다.

원본에 확인되지 않은 재배포 라이선스를 새로 붙이지 않습니다. 개인 강의 파일, 계정 정보, 개인 드라이브, 로그인 상태는 이 소스 묶음에 포함하지 않습니다.
