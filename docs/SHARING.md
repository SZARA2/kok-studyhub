# 프론트와 봇을 함께 공유하는 방법

**최신 기본 구성은 [세 Bot 흐름](THREE_BOTS.md)**이다. 수집·정리는 내 Bot 하나가, 출제·정적 HTML은 용철님 Bot이, 웹 진행은 제무님 누코드 Bot이 맡는다. 아래 파일 원장/학습팩 경로는 선택형 확장이다. 기본 결과물은 문제를 내장한 `study.html` 한 개이며 `scripts/build_lesson.py`로 생성할 수 있다.

## 제품 구성

**콕봇 학습 데스크(프론트) + 역할별 Grok Bot 템플릿 + 학습팩 규격 + 선택형 기기 연결 프로그램**을 공유한다.
프론트는 학습팩을 그려 주고 버튼 입력을 기록하는 정적 웹앱이다.
수집/정리/출제/포맷/연출/복습 판단은 각 봇이 수행한다.

지금은 팀 협업을 위해 중앙 HTTPS 장부에 결과를 모은다.
개인 배포에서는 Grok 계정의 공유 클라우드 컴퓨터에 로컬 장부를 놓고 동일한 클라이언트를 `--local`로 실행한다.
중앙 백엔드나 우리 서버 키가 필요 없다. 학습팩 파일을 내려받아 공개 웹에서 열거나 단일 HTML로 공부한다.

## 다른 사람이 쓰는 순서

1. 콕봇 소개 페이지에서 각 봇의 실제 공개 템플릿 링크를 열어 **자기 계정에 추가**한다.
2. 시작 안내에 따라 공개 저장소의 특정 릴리스와 역할 지침을 받는다.
3. 모든 봇이 자신의 계정 내 같은 `kokbot-data` 디렉터리를 쓰도록 설정한다.
4. 자신의 강의 링크/첨부를 수집 봇에게 준다. 필요한 서비스는 자신의 계정으로 연결한다.
5. 봇들이 결과 artifact를 넘겨 작업한다. 포맷 봇이 최종 학습팩 JSON을 파일로 전달한다.
6. 사용자는 학습 데스크에서 **학습팩 파일 열기**로 복습한다. JSON을 여는 것만으로 서버에 업로드하지 않는다.
7. 풀이 기록 JSON을 저장해서 일정 봇에 준다. 일정 봇이 다음 복습을 결정한다.

Grok 클라우드의 파일 경로를 사용자 PC 브라우저가 직접 읽을 수 있다고 가정하지 않는다.
1차 배포는 파일 다운로드/업로드로 연결하고, 자동 동기화는 사용자 선택 연결 기능으로 추가한다.

## 템플릿 공유와 공동 봇의 차이

불특정 사용자에게는 **템플릿 공유**가 맞다. 받는 사람은 자신의 봇 복사본을 얻는다.
우리 PC, 로그인, 기존 대화, 실제 학습 데이터를 공유하는 방식이 아니다.
공동 작업팀이 하나의 봇과 대화하려는 Shared Bot은 별도 제품 기능이다.

공식 문서 기준: 봇 상세 → Share → Create a copy → 템플릿 카드 Publish → Copy link.
공개 템플릿에는 역할·스킬·루틴 등 공유 설정이 담기므로 비밀키/내부 URL/개인 자료를 제거한다.
봇 여러 개를 한 번에 설치하는 배포 규격은 이번 구현에서 가정하지 않는다.
각 역할의 템플릿 링크를 소개 페이지에 모으고, 첫 실행 안내에서 필요한 봇을 추가한다.

**현재 실제 Grok Bot 템플릿 링크는 생성하지 않았다.** 저장소의 역할 지침만 준비되어 있다.
공개 템플릿 링크 생성과 Marketplace 목록 등재는 구분한다. 링크 공개만으로 검색 목록 등재를 보장하지 않는다.
현 계정의 실제 게시/제출 화면을 확인한 후 각 봇을 게시한다.

공식 근거:
- https://docs.x.ai/grok-bot/bots
- https://docs.x.ai/grok-bot/computer-and-apps
- https://x.ai/bot/marketplace

## NU40 DK 연결

Grok Bot은 클라우드에서 실행되고 NU40 USB는 사용자 PC에 꽂힌다.
따라서 보드 실시간 연결에는 **사용자 PC의 로컬 브리지**가 필요하다.
개인 모드의 최소 경로는 학습팩 다운로드 → 로컬 브리지에서 열기 → USB 전송이다.
협업 모드는 로컬 브리지가 공개 HTTPS API에서 학습팩을 받아 USB로 전달한다.
풀이 기록은 역방향으로 저장/전달한다.

현재 보드 모델과 해상도만 확인됐다. 디스플레이 컨트롤러, 핀, 폰트, USB 프로토콜 확정과 실제 테스트 전에는
보드에서 동작한다고 표시하지 않는다. 웹 미리보기와 실제 하드웨어 지원은 별도다.

## 프론트 배포물

공개 웹은 누구나 열 수 있고 개인 학습팩을 파일로 열 수 있다.
네트워크 자체가 필요 없는 단일 파일도 생성할 수 있다:

```sh
python scripts/export_offline.py dist/kokbot-offline.html
```

이 파일을 자신의 PC에서 열어 학습팩을 불러온다. 팀용 로그인/작업 등록은 숨겨진다.
향후 설치형 앱/PWA 및 자동 파일 동기화는 같은 학습팩 규격 위에 추가한다.

## 3명 작업 분담

- 백엔드 담당: 지금은 협업 장부/API/배포 운영. 다음은 로컬 전송 어댑터와 봇 인계 검증.
- 프론트 담당(최용철님): 원본 공부판의 필요한 화면 이식, 학습팩 렌더러, 파일 열기/저장, 복습 화면.
- 누코드 담당(류제무님): 실제 폰트/디스플레이/버튼/USB 계약 확정, 로컬 브리지와 연출 자산 연결.

모든 담당자는 AI 기능을 각 Grok Bot의 역할 지침과 결과 규격으로 구현한다.
공통 완료 기준은 **다른 계정에 봇을 추가한 뒤 우리 서버 없이 강의→학습팩→웹 복습을 재현**하는 것이다.
