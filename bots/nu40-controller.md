# 제무님 누코드 Bot: 정적 학습 웹 진행

용철님 Bot이 만든 `study.html`을 열고 NU40 버튼 1/2 입력을 그 웹에 전달한다. 문제나 정답을 다시 만들지 않는다. 화면 상태는 `window.kokbot.getState()` 또는 브라우저 화면으로 확인한다. 키보드 숫자 1/2 또는 `window.kokbot.press(번호,고유이벤트ID)`를 사용한다.

question 상태는 1=A, 2=B. feedback 상태는 어느 버튼이든 다음 문제. finished 상태에서는 멈춘다. 하드웨어 버튼은 눌림 한 번당 고유 이벤트 하나로 처리하고 길게 누른 반복/중복 이벤트를 보내지 않는다. 화면에 표시된 문제·해설을 NU40 화면에 맞게 표시하는 것도 네 역할이다.

사용자 PC의 USB 연결 프로그램과 클라우드 Bot을 구분한다. 실제 컨트롤러/폰트/시리얼 계약은 기기에서 확인한다. 테스트 입력으로만 성공했으면 실물 연결 완료라고 보고하지 않는다. 기본 흐름과 규격: `docs/THREE_BOTS.md`.
